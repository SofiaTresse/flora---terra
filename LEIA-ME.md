# Flora & Terra — Fotos dos produtos

Atualização pontual do projeto original: os três desenhos dos produtos em **“Escolhas que florescem”** e as seis ilustrações em **“Um pouco do nosso dia a dia”** foram substituídos por fotografias reais da web.

Os textos visíveis, preços, links, layout, cores e demais ilustrações decorativas foram preservados. Os textos alternativos das fotos foram ajustados para descrever as imagens. O JavaScript é idêntico ao original. O CSS recebeu apenas as regras para preencher os cartões com as fotografias e manter o efeito de aproximação ao passar o mouse.

## Abrir e atualizar no GitHub

Abra `index.html` para visualizar. Para atualizar o repositório `SofiaTresse/flora---terra`, envie o conteúdo desta pasta para a raiz do repositório, incluindo a nova pasta `assets/images`.

Os arquivos necessários para a alteração são:

- `index.html`;
- `assets/css/style.css`;
- todas as fotos de `assets/images`.

O site continua compatível com GitHub Pages, sem instalação ou compilação.

## Fotografias

As imagens dos produtos são referências ilustrativas de fotografias encontradas na web, e não registros de um estoque real. Não foram utilizadas imagens geradas por IA.

As fontes e os créditos estão em `CREDITOS-IMAGENS.md`.
